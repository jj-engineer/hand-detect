#  * mediapipe 0.10.14 has Windows wheels only for CPython 3.9-3.12 (win_amd64): Python 3.13+ will NOT work.
#  * matplotlib / jax / jaxlib are required by mediapipe's own metadata ("import mediapipe" imports matplotlib at load
#    time); they are pinned so pip does not backtrack into an untested combination.
